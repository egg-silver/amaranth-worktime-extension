아마란스 그룹웨어(`gw.goorm.io`)에 들어가지 않고, 크롬 툴바에서 이번 달 근무시간과 오늘 퇴근 가능 시각을 확인하는 비공식 확장입니다.

## v1.2.0 에서 달라진 것

**이제 확장 안에서 업데이트할 수 있습니다.** 지금까지는 새 버전이 나오면 zip 을 받아 압축을 풀고 폴더에 덮어쓴 다음 `chrome://extensions` 에서 새로고침을 눌러야 했는데, 이번 버전부터는 **업데이트** 버튼 한 번이면 끝납니다.

설정의 **폴더 설정**에서 설치 폴더를 한 번 지정해 두면 그 위치를 기억합니다. 다음부터 새 버전이 나오면 버튼을 눌러 바로 내려받아 교체하고, 확장이 알아서 다시 로드됩니다.

안전장치도 들어가 있습니다. 고른 폴더가 실제로 지금 돌고 있는 설치 폴더인지 검사하고, 다른 복사본이면 거부합니다. 다운로드가 실패하면 기존 파일은 건드리지 않고, 교체 도중 문제가 생기면 원래 파일로 되돌립니다. 폴더 선택창과 다운로드가 진행되는 동안 팝업이 닫혀도 이어지도록 별도 탭에서 처리합니다.

다만 **작업 중에는 탭과 브라우저를 닫지 마세요.** 강제 종료까지 복원을 보장하지는 않습니다.

## 설치

아래 Assets 에서 `amaranth-worktime-extension.zip` 을 받아 압축을 풉니다. 압축 푼 폴더를 먼저 최종 위치로 옮기세요 — 크롬은 이 확장을 폴더 경로로 기억하기 때문에, 로드한 뒤에 옮기거나 이름을 바꾸면 확장이 깨집니다. 바탕화면과 문서 폴더는 macOS iCloud 동기화 대상이라 파일이 클라우드로 밀려나면 확장이 멈추므로, `~/chrome-extensions/` 처럼 동기화되지 않는 곳을 권합니다.

폴더를 옮긴 다음 크롬에서 `chrome://extensions` 를 열고 오른쪽 위 **개발자 모드**를 켠 뒤, **압축해제된 확장 프로그램을 로드합니다**로 그 폴더를 선택합니다. 마지막으로 그룹웨어에 한 번 접속하면 사번을 읽어옵니다. 이후로는 그룹웨어에 들어가지 않아도 됩니다.

**이미 쓰고 있다면** 이번 한 번만 수동으로 올려야 합니다. 새 zip 을 받아 기존 폴더에 덮어쓰고 `chrome://extensions` 에서 새로고침을 누르세요. 설정과 내 그룹은 그대로 남습니다. 다음 버전부터는 확장 안에서 업데이트됩니다.

무언가 동작하지 않으면 팝업 하단 **설정 → 연결 진단**에서 어느 단계가 막혔는지 확인할 수 있습니다. 자세한 내용은 [README](https://github.com/egg-silver/amaranth-worktime-extension#readme)를 참고하세요.

## 기능

* 오늘 퇴근 가능 시각과 남은 시간 — 하루 소정 근로시간 기준, 점심시간 반영
* 이번 달 초과·부족 누적 — 다른 날 더 일한 시간이 오늘 목표에서 자동으로 빠짐
* 남은 근무일 — 주말과 공휴일을 뺀 실제 근무일 기준
* 근태 달력 — 근무시간을 농도로 표시, 퇴근 미등록일 표시, 날짜를 누르면 그날 상세
* 연차 현황 — 일반 연차·보상 휴가·대체 휴가를 나눠서 표시
* 휴가 달력 — 팀 전체 휴가를 한 달치로, 부서 필터와 내 그룹 필터
* 그룹웨어 알림 — 3분마다 확인해 데스크톱 알림과 툴바 배지로 표시
* 새 버전 확인과 **확장 안에서 업데이트**
* 하루 근무시간 직접 설정, 사번 수동 입력, 연결 진단

## 알아둘 점

* 조회 전용입니다. 출퇴근 등록 같은 쓰기 동작은 하지 않습니다
* 각자 브라우저의 그룹웨어 로그인 세션으로만 동작하며, 모든 데이터는 각자 브라우저에만 저장됩니다
* 그룹웨어가 공개한 API 가 아니라 웹 화면이 쓰는 요청을 흉내 냅니다. 그룹웨어가 바뀌면 동작이 멈출 수 있습니다
