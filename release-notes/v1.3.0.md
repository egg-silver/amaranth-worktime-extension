아마란스 그룹웨어(`gw.goorm.io`)에 들어가지 않고, 크롬 툴바에서 이번 달 근무시간과 오늘 퇴근 가능 시각을 확인하는 비공식 확장입니다.

## v1.3.0 에서 달라진 것

**팀근태 탭이 생겼습니다.** 우리 팀이 오늘 몇 시에 출근했는지 한눈에 봅니다. 근무 중·퇴근·미출근을 색으로 구분하고, 퇴근까지 찍힌 사람은 근무시간(점심 제외)까지 보여줍니다.

팀원은 두 가지로 등록합니다.
- **이름과 사번** 을 줄마다 적기 (사번만 적어도 되고, 나중에 이름을 붙일 수 있어요)
- 받은 **공유 코드** 붙여넣기 — 설정에서 만든 내 코드를 팀원에게 보내면 서로 등록됩니다

붙여넣기는 공백 없이 붙여 넣어도 알아서 나눠 등록합니다. 등록한 팀원은 각자 브라우저에만 저장되고, 다른 곳으로 나가지 않습니다.

**설정 화면도 정리했습니다.** 버전을 맨 위로 올리고, 입력칸과 저장 버튼을 한 줄로 붙였습니다.

## 설치

아래 Assets 에서 `amaranth-worktime-extension.zip` 을 받아 압축을 풉니다. 압축 푼 폴더를 먼저 최종 위치로 옮기세요 — 크롬은 이 확장을 폴더 경로로 기억하기 때문에, 로드한 뒤에 옮기거나 이름을 바꾸면 확장이 깨집니다. 바탕화면과 문서 폴더는 macOS iCloud 동기화 대상이라 파일이 클라우드로 밀려나면 확장이 멈추므로, `~/chrome-extensions/` 처럼 동기화되지 않는 곳을 권합니다.

폴더를 옮긴 다음 크롬에서 `chrome://extensions` 를 열고 오른쪽 위 **개발자 모드**를 켠 뒤, **압축해제된 확장 프로그램을 로드합니다**로 그 폴더를 선택합니다. 마지막으로 그룹웨어에 한 번 접속하면 사번을 읽어옵니다.

**이미 v1.2 를 쓰고 있다면** 설정의 **업데이트** 버튼으로 바로 받을 수 있습니다. 처음 쓰거나 폴더가 지정되지 않았다면 안내에 따라 설치 폴더를 한 번 지정하면 됩니다.

## 기능

* 오늘 퇴근 가능 시각과 남은 시간 — 하루 소정 근로시간 기준, 점심시간 반영
* 이번 달 초과·부족 누적, 남은 근무일
* 근태 달력 — 근무시간 농도, 퇴근 미등록일, 날짜별 상세
* 연차 현황 — 일반 연차·보상 휴가·대체 휴가 구분
* 휴가 달력 — 팀 전체 휴가, 부서·내 그룹 필터
* **팀근태 — 우리 팀 오늘 출근 현황 (신규)**
* 그룹웨어 알림 — 데스크톱 알림·툴바 배지
* 새 버전 확인과 확장 안에서 업데이트

## 알아둘 점

* 조회 전용입니다. 출퇴근 등록 같은 쓰기 동작은 하지 않습니다
* 각자 브라우저의 그룹웨어 로그인 세션으로만 동작하며, 모든 데이터는 각자 브라우저에만 저장됩니다
* 그룹웨어가 공개한 API 가 아니라 웹 화면이 쓰는 요청을 흉내 냅니다. 그룹웨어가 바뀌면 동작이 멈출 수 있습니다
