# amaranth-worktime-extension

아마란스 그룹웨어(`gw.goorm.io`)에 들어가지 않고, 크롬 팝업에서 이번 달 근무시간과
오늘 근무 시간과 퇴근 가능 시각을 확인하는 비공식 확장.

## 설치

1. 폴더를 **최종 위치로 먼저 옮긴다** (아래 주의 참고)
2. 크롬에서 `chrome://extensions` 열기
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택
5. 그룹웨어(`https://gw.goorm.io`)에 **한 번** 접속 — 사번을 읽어 저장한다
6. 툴바의 시계 아이콘 클릭

5번은 최초 1회만 필요하다. 그 뒤로는 그룹웨어에 들어가지 않아도 된다.

> **폴더 위치를 먼저 정할 것.** 크롬은 이 확장을 폴더 경로로 기억한다.
> 로드한 뒤에 옮기거나 이름을 바꾸면 확장이 깨지고 팝업이 "페이지를 열 수 없습니다" 가 된다.
> 바탕화면·문서 폴더는 macOS iCloud 동기화 대상이라 파일이 클라우드로 밀려나면 확장이 멈춘다.
> `~/chrome-extensions/` 처럼 동기화되지 않는 곳에 두는 것이 좋다.

## 화면

**[오늘]**
맨 위 카드를 누르면 담기는 값이 바뀐다. 사람마다 궁금한 게 달라서 세 가지를 돌려 쓴다.

| 보기 | 큰 값 | 누구에게 |
|---|---|---|
| 오늘 근무 시간 | `3시간 19분` | 지금까지 얼마나 일했는지 (기본값) |
| 퇴근 가능 시각 | `18:12` | 몇 시에 나갈 수 있는지만 보면 되는 사람 |
| 이번 달 누적 | `56시간 34분` | 월 단위로 관리하는 사람 |

진행바도 함께 바뀐다 — 앞의 둘은 오늘(8시간) 기준, 마지막은 이번 달(소정) 기준.
고른 값은 저장되어 다음에 열 때도 유지된다.

그 아래로 오늘 남은 시간(하루 8시간 기준), 이번 달 초과·부족 누적,
남은 근무일(남은/전체), 퇴근 미등록 경고

다른 날 소정보다 더 일한 시간은 자동으로 오늘 목표에서 빠진다.
"이번 달 초과·부족"이 그 적립분이다.

**[기록]**
월 달력. 앞뒤 달로 넘길 수 있다. 칸을 누르면 그날의 출퇴근과 인정 근무시간이 아래에 뜬다.

| 표시 | 뜻 |
|---|---|
| 블루 농도 | 그날 근무시간. 진할수록 오래 일한 날 |
| 오렌지 칸 + `연차` | 종일 휴가 (칸 전체가 찬다) |
| 아래 절반 오렌지 + `반차` | 반차. 반반차는 아래 1/4만 찬다 |
| 붉은 칸 + `미등록` | 출근만 찍고 퇴근을 안 찍은 날 |
| 붉은 날짜 + 이름 | 일요일·공휴일 (`추석`, `대체휴일`) |
| 블루 테두리 | 오늘 |

칸은 실제 `button`이라 키보드로도 넘길 수 있고, 선택 상태가 `aria-pressed`로 노출된다.

달력 아래에 근무일 수가 어떻게 나왔는지 함께 적는다 — `근무일 20일 — 평일 22일 − 공휴일 2일`.
휴가는 근태캘린더에서 가져오므로 **앞으로 예정된 휴가도** 보인다.

**남은 연차**는 [오늘] 탭 아래쪽과 [기록] 탭 휴가 목록 옆에 나온다.
일반 연차와 보상 휴가(대체 휴가가 있으면 그것도)를 나눠서 보여준다 —
`연차 9.5 · 보상 2.4`. 그룹웨어 값을 그대로 쓰므로 소수점까지 맞다.

**[근태]**
팀 전체 휴가 달력. 그룹웨어 일정 화면과 같은 데이터를 쓴다.
날짜 칸에는 그날 쉬는 사람 수만큼 점을 찍고(5명 이상이면 `+N`), 내 휴가가 있는 날은 주황 점과 배경으로 구분한다.
날짜를 누르면 아래에 그날 명단이 뜬다 — 이름·부서·휴가 종류. 내 항목에는 `나` 배지가 붙고 맨 위로 온다.

**[알림]**
그룹웨어 알림 목록. 안 읽은 알림은 진한 글씨와 파란 점으로 표시된다.
제목을 누르면 상세가 새 창으로 열리고 읽음 처리된다. 점만 누르면 창을 열지 않고 읽음 처리한다.

백그라운드에서 3분마다 새 알림을 확인해 데스크톱 알림으로 띄우고,
안 읽은 알림이 있으면 툴바 아이콘에 빨간 점을 올린다. 데스크톱 알림을 누르면 상세가 열린다.
설치 직후 첫 확인은 기준선만 잡고 알림을 띄우지 않는다.

**[설정]** — 하단 "설정" 버튼으로 연다.
적용된 근무규칙, 하루 근무시간 변경, 연결 진단, 사번 직접 입력.

무언가 안 될 때는 **연결 진단**을 먼저 본다. 사번을 읽었는지, 쿠키가 있는지,
각 API 가 응답하는지 한 줄씩 보여주므로 어디서 막혔는지 바로 드러난다.

## 갱신과 캐시

하단 **↻ 새로고침**은 캐시를 버리고 서버에서 다시 가져온다.
평소에는 팝업을 열 때마다 갱신되고, 일자별 기록·공휴일·휴가는 30분 캐시된다.

## 확장 버전 업데이트

설정의 **폴더 설정**은 설치 폴더를 지정하고 IndexedDB에 저장하는 기능입니다. 설정이 저장되면 버튼 옆에 체크 표시가 나타납니다. 폴더 설정만으로는 업데이트하지 않습니다.

1. 새 버전이 표시되면 기존 버전 영역의 **업데이트** 버튼이나 업데이트 알림을 누릅니다.
2. 저장된 폴더에 쓰기 권한이 있으면 바로 다운로드·교체를 시작합니다.
3. 폴더가 없으면 설치 폴더 지정을 안내합니다. 폴더를 지정하면 저장하고 업데이트를 이어갑니다.
4. 저장된 폴더의 권한이 만료되면 **권한 허용하고 업데이트**를 눌러 이어갑니다.
5. 완료되면 확장이 자동으로 다시 로드됩니다.

폴더 선택창과 다운로드 동안 팝업이 닫혀도 작업을 이어갈 수 있도록 별도 탭을 사용합니다.

선택한 폴더가 실제 실행 중인 설치 폴더인지 임시 파일로 검사합니다. 같은 확장의 다른 복사본은 거부합니다.
다운로드 실패 시 기존 파일을 변경하지 않으며, 교체 도중 오류가 발생하면 메모리에 보관한 기존 파일로 복원합니다.
브라우저 강제 종료나 시스템 중단까지 복원을 보장하지는 않으므로, 작업 중 탭이나 브라우저를 닫지 마세요.
복구 실패가 표시되면 릴리스 ZIP으로 파일을 수동 복원해야 합니다. 배포에서 사라진 파일이나 사용자가 추가한 파일은 삭제하지 않습니다.

업데이트 확인과 설치는 `egg-silver/amaranth-worktime-extension`의 최신 공개 릴리스를 사용합니다. 릴리스 태그는 `v<manifest 버전>` 형식으로 맞춰야 합니다.
따라서 아직 릴리스되지 않은 버전은 설치하지 않습니다. GitHub API 제한이나 네트워크 오류가 나면 나중에 다시 시도하거나 GitHub 릴리스의 ZIP을 수동으로 받아 적용하세요.
이 기능이 없는 기존 설치에는 새 파일을 한 번 수동 적용해야 합니다. 이 변경은 확장 ID를 고정하지 않습니다.

## 키 조작

전역 단축키는 쓰지 않는다. 아래는 **팝업이 열려 있는 동안에만** 듣는다.

| 키 | 동작 |
|---|---|
| `Alt+Shift+E` | 오늘 → 기록 → 근태 → 알림 탭 전환 |
| `Alt+Shift+T` | 히어로 값 전환 (오늘 근무 시간 → 퇴근 가능 시각 → 이번 달 누적) |

달력 칸은 실제 `button` 이라 `Tab` 으로 옮겨 다니며 `Enter` 로 열 수 있다.
사이드패널로도 열 수 있다.

## 디자인

구름 디자인 시스템(Vapor) 토큰 기준. 중립 회색 화면에 블루 강조 하나,
카드는 1px 테두리 + 12px 라운드, 글꼴은 Pretendard Variable(`fonts/`에 내장).

## 동작 방식

그룹웨어 쿠키(`oAuthToken`, `signKey`)를 읽어 요청마다 HMAC 서명을 만들어 API를 호출한다.
비밀번호를 저장하지 않고, 데이터를 외부로 보내지 않는다. 모든 계산은 브라우저 안에서 끝난다.

자세한 설계는 [설계 문서](docs/DESIGN.md)에 있다. 쓰는 API 와 계산 규칙이 정리되어 있다.

## 테스트

```bash
npm test
```

네트워크는 타지 않는다. 네 갈래를 본다.

| 파일 | 보는 것 |
|---|---|
| `calc.test.js` | 근무시간·남은 근무일·달력 계산 |
| `alerts.test.js` | 알림 읽음 판정과 정렬 |
| `background.test.js` | 서비스 워커가 뜨고 메시지에 답하는지 |
| `manifest.test.js` | 코드가 쓰는 `chrome.*` API 가 manifest 에 선언돼 있는지 |

마지막 것은 실제로 겪은 사고를 막는다. manifest 에서 `commands` 키를 빼면
`chrome.commands` 가 `undefined` 가 되고, 그걸 참조하는 코드 한 줄 때문에
서비스 워커 전체가 뜨지 않는다.

## 알아둘 것

- 그룹웨어 세션이 만료되면 확장도 동작하지 않는다. 그룹웨어에 다시 로그인해야 한다.
- 퇴근 전에 보이는 오늘 근무시간은 추정치다. 퇴근을 등록하면 서버 확정값으로 바뀐다.
- 비공식 확장이라 그룹웨어가 서명 방식이나 응답 형식을 바꾸면 깨진다.
- 조회 전용이다. 출퇴근 등록 기능은 넣지 않았다.
